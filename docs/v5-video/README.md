# 工坊短片与入口改造

日期：2026-09-28。此轮在现有第四版网站上增加介绍短片与工坊指南，保留作品格式、几何计算及打印边界。所有项目资料与产物只在本项目目录处理；技能目录仅作为工具说明与可复用能力来源。没有公开部署。

## 制作方向

短片围绕“一刀下去，展开后会是什么样”展开，以真实页面和操作结果为主体，沿用米白、朱红、宋体标题与纸张质感。剪纸装饰只用于品牌画面，不能冒充真实剪切结果。配音用短句与适度停顿解释操作，避免功能列表式宣传。

“学习手册”扩展为“工坊指南”，包含认识工坊、动手指南、我们的团队。五人信息先呈现职责分工，不填造姓名、履历、获奖或试用成果。队长为项目负责人，其他职责为交互与视觉、前端与交互、几何与数据、内容与体验测试。

## 验收范围

- 实际可播放的 MP4、中文字幕、封面、可编辑制作工程及无背景音乐版本。
- 首次进入可选看短片、跟着操作或直接探索；收回动画指向侧栏固定入口。
- 工坊指南可重播，原手册功能保留，键盘、窄屏及减少动态效果可用。
- 视频播放暂停站内音乐，刷新不会自行出声。
- 验证真实媒体解码、字幕/海报服务类型、首访偏好、漫游与原作品隔离。

## 工作边界与证据

使用动态技能路由器 V4，routeId 为 `1a252c0e-d3d6-4c4c-bd30-7aefa32cb1fe`。采用 video-shotcraft 的真实页面采集和逐镜头制作方法、FFmpeg 编码与声音处理、Firecrawl 来源抓取。Adobe 初始化实际返回 `MCP -32603 Internal error`，未上传素材或使用其渲染结果；改用可验证的本地视频工具链。路由候选中的域名和发布工具与本任务无关，未调用。
