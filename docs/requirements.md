# 已确认需求与接口

用户于2026-09-26确认方案并要求实施。目标是独立完成一件教育交互软件，不是开发AI Agent。学习对象为成年剪纸初学者，运行时不调用AI或云服务。

## 功能与数据

四个单元：折叠与对称、裁去与保留、连通与分离、尺寸与实物；六案例加两迁移任务。编辑、双视图、历史、诊断、候选比较、IndexedDB保存、原生JSON导入导出、SVG和A4模板构成一条完整流程。

`src/types.ts` 是共享数据接口。ProjectDocument版本为1，包括纸张、固定折法、cuts与cursor、教学进度和匿名事件。光标后的cuts保留用于重做；在旧光标处新增操作删除重做分支。

折叠域（h=纸张边长/2）：2层为[0,h]×[-h,h]；4层为[0,h]×[0,h]；8层三角(0,0)(h,0)(h,h)。反射、坐标交换生成所有层，统一使用纸心坐标，不从屏幕像素恢复几何。

Analysis包含版本、折叠和展开Region、外轮廓及洞、面积、连通分量、操作步骤、目标检查及不确定状态。诊断在Web Worker中执行；请求编号隔离过期结果。修复基于原操作，重新验证全部后续步骤及课程目标，不能只检查最终连通。

## 约束

第一刀后锁定折法。无边界入口、自交、非有限数和超限图案必须拒绝。课程成功不能通过裁空或撤销所有刀来取得。分离只在明确要求连通的任务里视为目标冲突。0.01mm是网格，不是打印精度或制造保证。

## 明确不包含

任意图片转剪纸、自由曲线、通用SVG导入、3D物理折纸、真实撕裂、云同步、账号、支付、自动公开部署。照片和试用结论不能生成冒充事实。
