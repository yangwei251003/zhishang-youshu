- 元数据核验方式：`https://api.bilibili.com/x/web-interface/view?bvid=<BV号>`；10 条均返回 code=0、state=0、作者与时长。
- 已核验：10 条独立来源存在；作者与标题可追溯；官方嵌入参数有文档支持。10/10 条在独立 Chrome headless 会话中载入官方播放器并实际解码，初始均为 paused=true、muted=true，显式调用媒体播放后时间推进超过 2 秒并存在已解码画面。证据见 [media-playback.json](v3-implementation/evidence/media-playback.json) 与 [代表截图](v3-implementation/evidence/media-playback.png)。这项是媒体可达性／解码抽查，不等同于完整观看或站内播放器按钮验证。4 条暂停封面存在约 0.22–0.38 秒的初始时码，已保留原始数据，不把静止封面的非零时码误判为自动播放。
- 待验证：每段全片真人观看、每个地区／网络的实际播放、原站广告与账号要求、真人试用及实体剪纸。第三方播放器可能随原站变化；不能把 iframe load 事件当成视频已经成功播出的证据。
- 离线边界：外站视频本身需要网络，核心工坊与本地静态观察内容不依赖视频；这是用户「嵌入优先」决策下的设计，不将外站视频宣传为离线可播。
- 跨站播放器限制：本站不能读取跨域播放器内部状态，iframe load 只结束载入提示。来源链接始终保留，若原站返回空白／内部错误，用户也可点击「改看文字步骤」卸载播放器并显示本地三步摘要。断网事件和 15 秒初次载入超时会自动回到静态内容。

- 真实控件收口：重新观察实际底栏后，在新会话通过可见底栏UI完成V05播放与暂停（未调用媒体play API）；时间推进2.02秒、55帧解码、640×360，初始仍暂停/静音。证据：[media-site-controls.json](v3-implementation/evidence/media-site-controls.json)及同名PNG。此项只验证1条的站内控件，保留上一项选错隐藏控件的失败记录。
