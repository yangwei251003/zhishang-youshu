## 覆盖内容

59项自动测试由几何与Worker 25项、文件与存储22项、课程联测12项组成。独立预期样例涵盖完整纸、镜像面积、孔洞、洞中孤岛、横贯裁断、点接触、共线边界、极细连接、重复剪口、折轴剪口、退化输入和50次剪切。修改早期步骤后检查后续可进入性；候选修复保留当前任务目标，并检查已撤销历史能否重做。

浏览器验证涵盖新建、合法/非法剪口、参数修改、撤销重做、首刀折法锁定、预测、分离解释、候选对照与应用、学习完成记录、多作品存档、项目导出重导入、非法导入不覆盖现有作品、SVG输出、打印窗口、逐层展开、窄屏、基础反馈、重做同课、新匿名参与者和计算线程故障恢复。

故障注入检查：已有通过结果后故意令计算线程失败，成绩记录与打印按钮必须停用；恢复线程后能继续计算，不把旧结果当作新结果。

首轮浏览器脚本有两项因测试定位器未匹配折法下拉框而超时。调整为对话框内的真实下拉控件后，新建流程和最终14项全量回归均通过。整合审查同时修正了候选应用目标检查、撤销历史检查和分步展开顺序。

## 性能与离线运行

最终回归中，50刀×8层在浏览器计算线程内首次计算（含初始化）：Chrome约324.5ms，Edge约489.6ms。两者都得到有效50步、1片保留纸、面积25390mm²。该数据来自本机一次回归，不代表其他设备的保证；测试上限为5秒。

生产验证阻断全部非localhost/127.0.0.1网络请求，实际完成首次加载、本地字体加载、计算Worker、撤销重做、IndexedDB保存重开及SVG下载。每个浏览器加载15个本地资源，未发起外部请求。没有实际拔网线，也没有测试未安装Node的机器。运行包需要本机Node，本版不是双击HTML即可运行的程序。
