# 纸上有数｜多场景推演验证

日期：2026-09-27。方法：以真实使用场景为脚本，对 V2 现状逐场景推演（含本轮 5191 端口实测证据），给出 V3 防备要求。"推演"不是真人测试；现场表现须在功能冻结后按此清单实地彩排。

## 场景一：评委评审演示（最重要）

**脚本：** 评委拿到运行包/笔记本，双击启动，给 3–5 分钟自由探索，可能打开 DevTools，可能把浏览器缩到 1100px 或投影缩放，可能打断引导。

|环节|V2 现状推演|风险|V3 要求|
|---|---|---|---|
|双击启动|启动第二版.cmd→5189，一次到位；端口被占时报错退出|演示机若 5189 被占用即冷场|V3 用 5190 新端口；演示前 checklist：先开任务管理器确认端口空闲、只启动一个版本|
|首屏|欢迎卡＋团花 hero，第一印象好|控制台 6 条 CSP 字体错误（实测）|P0-11 修复，演示前 F12 检查 0 错误|
|跟引导走|六步可走通|1035–1300px 下卡片遮住预测选项（实测证据 03/07）——评委笔记本+缩放极易命中|P1-11 避让定位；五视口回归|
|自由探索核心亮点|修复对照最出彩|评委不知该点哪；引导没讲"修复"|任务栏把"读懂问题→修好它"列为任务 5/6，演示路径自然走到修复对照|
|问"和现实剪纸什么关系"|V2 无实剪内容|只能口头解释|"纸上成真"视频当场播放一段 20 秒自拍实剪|
|问"能剪什么图案"|抽象几何样例|文化感染力不足|双喜/蝴蝶纹样课当场展开|
|现场网络|全本地资源，断网可跑|V3 新增素材必须同样本地化|断网验收（D7）|
|现场声音|全站无声|安静演示安全；若加音乐默认关|音乐默认关、音效默认开（音量小），评委机先静音检查|

**演示动线建议（写进 docs/demo-script.md 的 V3 版）：** 欢迎卡 → 任务栏看一眼 7 任务 → 跟到"剪下第一刀" → 直接跳"留住这一线"展示分离诊断 → 修复对照（3 片→1 片）→ 打印模板标尺 → 播一段实剪视频 → 双喜课展开收尾。全程 ≤4 分钟。

## 场景二：高校通识课课堂（教师带 30 人）

|环节|推演|V3 要求|
|---|---|---|
|课前分发|本地运行包 zip，解压双击即可；无需网络与安装|保持；教师打印包（P2）可提前发学生页|
|学生首用 5 分钟|漫游可跳过，但跳过后新手无路径|任务栏给"跳过的学生"留了可见的 7 步路径，教师不用逐个讲|
|课堂任务|教师口头布置"完成留住这一线"|任务栏 5/6 即现成课堂作业；学习记录 JSON 可作为过程性作业收交（本地导出，无隐私问题）|

|投影|投影 720p/缩放 125–150% 常见|中屏修复（P1-12）；200% 缩放等效回归|

## 场景四：家庭/移动端（手机 390px）

实测 V2：预测置顶、双标签、画布 334px、无横溢出（证据 15）。推演风险：

- 触控拖拽精度：本轮未真机验证 → V3 冻结前必须至少一款真机抽查；剪口太小难命中时可考虑放大画布默认缩放。
- 手机扬声器常静音 → 音效不作为唯一反馈（本就不是）。
- 引导任务栏在手机的折叠卡不得遮挡预测区（五视口回归覆盖）。

## 场景六：功能冻结后彩排清单（10-13 起执行）

1. 干净 Windows 机（无 Node 环境）解压运行包，双击启动第三版.cmd，全流程一次走通；
2. F12 控制台 0 错误；断网重走核心流程；
3. 一款真机手机（触控）走完任务栏 7 任务；
4. 真实打印一份双喜模板，量 100mm 标尺，实剪并拍照记录（含失败）；
5. 8–12 位成年用户试用按 manual-validation 执行；
6. 演示动线计时彩排 3 次（≤4 分钟），录最终演示视频。

## 推演总结

最可能出问题的环节排序：①中屏/缩放下引导卡片遮挡（已实测复现，必修）→ ②评委机控制台字体错误（已实测，必修）→ ③修复计算等待无反馈（故障注入未测，防备）→ ④打印弹窗被拦截（有提示但无备用路径）→ ⑤真机触控未验证（冻结前补测）。V3 规格的 P0/P1 项已覆盖全部五项。
