## 2. 主题 A：任务式新手引导"纸上第一课"（P0-A）

### 2.1 结构：任务栏 + 分幕引导

两层互相独立又互相衔接：

- **任务栏（ApprenticeTasks）**：持久存在的新手清单，是"骨架"。
- **分幕引导（沿用并扩展 OnboardingTour）**：从任务栏或欢迎卡进入的实景高亮，是"讲解"。V2 六步漫游的交互机制（高亮、键盘、跳过记忆、练习副本、origin=onboarding）全部保留复用。

### 2.2 七个任务定义

|#|任务 id|标题|完成条件（真实行为，非点击）|对应分幕|
|---|---|---|---|---|
|1|tour-interface|认识这间工坊|看完 30 秒导览（可快进的 4 幕静态说明卡：这是什么/一张纸的循环/非遗一句话/怎么保存）|新导览，不做实景高亮|
|2|first-prediction|留下第一次预测|任一学习课提交一次预测|实景：预测面板|
|3|first-cut|剪下第一刀|真实拖拽产生一刀 `cut_applied`|实景：折叠画布|
|4|first-unfold|看纸展开|完成一次分步展开|实景：展开控制|
|5|find-problem|读懂一个问题|在"留住这一线"（或任一分离案例）查看分离诊断：点击"第 N 步出现分离"定位该刀|实景：结构观察＋历史|
|6|first-repair|修好它|应用一次修复候选或手动修改后目标通过|实景：修复对照弹窗|
|7|print-template|带到纸上|打开一次打印纸样（或弹窗被拦截时导出打印 HTML）|实景：导出区|

设计要点：

- 任务 2/3/4 与 V2 漫游的练习副本机制相同：在独立练习副本里完成也算，记录 `origin=onboarding`，不污染正式记录。任务 5/6 用正式课"留住这一线"但状态独立，不影响该课首次独立完成的判定（任务完成 ≠ 课程独立完成，两者分开记录）。
- **进度持久化**：新键 `paperWorkshop.apprentice.v1`，结构 `{ tasks: {id: completedAtISO}, status: 'active'|'graduated'|'dismissed', version: 3 }`。与作品 JSON、引导偏好键分离；存储不可用时退化为会话内。
- **老手路径**：欢迎卡"直接进入，不再提示"→ 任务栏初始即收起为一行"新手任务（0/7）＋展开"；设备已有作品时不主动展开。任务栏任何时刻可"跳过全部"。
- **毕业**：7/7 后任务栏播放印章"出徒"动效（≤1.2s，尊重减少动态偏好），随后永久收起为一枚"已出徒"印章按钮，点击可回看任务与重进任意分幕。

### 2.3 任务栏 UI

- 桌面：左栏顶部（课程目录之上），固定约 7 行高，每行：勾选框＋任务名＋问号（点开该任务的 30 字说明）。当前推荐任务行用朱砂左边条标出，文案"建议下一步：留下第一次预测"。
- 手机：折叠为一张卡片"新手任务 · 2/7"，展开覆盖当前实验卡上方。
- 完成反馈：打勾＋印章式"已成"小印记（SVG，非 emoji），300ms，不弹阻断对话框。

### 2.4 分幕内容重写（每幕三段式：做什么 / 为什么 / 和真纸的关系）

V2 六步全部重写文案，并新增第 5、6 幕（找问题、修复）与第 7 幕（迁移）。示例：

> 第 5 幕 · 找出哪里断了
> 做什么：展开结果里，这张纸变成了 3 片。点一下"第 2 步出现分离"，看看是哪一刀。
> 为什么：剪纸里有一条铁律——**不断**。窗花、双喜、团花，都要能从纸上完整地拿起来。
> 和真纸的关系：在真纸上，这一刀剪下去，窗花就散成几片了。屏幕上我们可以倒回去改，真纸不能——所以先在这里练。

> 第 0 幕（新导览第 3 卡）· 一张纸的文化
> 中国剪纸是联合国人类非物质文化遗产。每一幅窗花的骨架，都是折叠、对称与连通——这就是"纸上有数"的"数"。

每幕 ≤3 段、每段 ≤2 行；总漫游时长目标 3–5 分钟（含实操），比 V2 长但必须"每幕都可只看说明跳过"。

### 2.5 引导卡片定位修复（P1-11，随本主题一并改）

- 定位策略改为四象限避让：先尝试目标右侧，其次下方，再次上方，最后左侧；任一方向与目标矩形相交面积 >15% 即换下一方向；全部不足时（视口 <1300px 且目标在右栏/弹窗）退到底部停靠卡（与窄屏相同实现）。
- 锚点等待、ResizeObserver、滚动重算逻辑保留。
- 新增回归：1100×800 与 1280×800 视口跑完整引导，断言每步卡片与锚点矩形不相交，且所有交互控件可点。

### 2.6 事件记录

新增事件类型（沿用 V2 value 编码，eventVersion=2）：`apprentice_task_done`（taskId）、`apprentice_graduated`、`apprentice_dismissed`。教程任务完成与正式学习事件分开，origin 语义不变。

## 4. 主题 C：沉浸感——音效与音乐（P0-C）

### 4.1 剪纸音效（默认开）

|时机|音效|实现|
|---|---|---|
|落剪成功 cut_applied|干脆的"咔嚓"（50–80ms）|Web Audio 合成（噪声+带通+快衰减包络）或 ≤20KB 授权样本|
|分步展开每一步|纸张摩擦"沙"（150–250ms）|合成噪声+低通扫频|
|目标通过/任务完成|轻"叩印"一声|合成短促低频＋一点泛音|
|剪口被拒绝|钝"笃"（不振铃）|合成|
|修复应用|纸屑轻落|合成，极轻|

- 新模块 `src/audio/sfx.ts`：懒加载 AudioContext（首个用户手势后创建），全部音效可由设置一键关；`paperWorkshop.audio.v1 = { sfx: true, music: false }`。
- 合成方案零版权风险，优先；若用样本必须 CC0 并登记。
- 尊重 `prefers-reduced-motion` 时音效保留（声音不是动效），但提供总开关；播放 API 失败一律静默。

### 4.2 环境轻音乐（默认关）

- 入口：顶栏一枚"熏香/音符"按钮（Lucide `Music`/`Music2`），点击开/关；状态持久化到上面同一偏好键。**默认关，绝不自动播放。**
- 曲目：1–2 首循环纯音乐，音量约 -25dB，风格古筝/笛/钢琴。音源以品质为先：耳聆网、淘声网、Freesound、FreePD、Musopen 等公开素材站任选，来源与作者登记 `docs/content-sources.md`；也可用 Web Audio 生成式氛围音（持续音+五声音阶随机动机，零外部素材）。
- 文件 ≤3MB/首，本地存放 `public/audio/`；加载失败静默隐藏按钮。

### 4.3 展开镜像动效（P1）

- 分步展开/整体展开时，展开态 SVG 从折叠态镜像"生长"：对每层镜像组做 300–500ms 的 scale/opacity 过渡（SVG `<g>` transform），层序与真实展开顺序一致。
- `prefers-reduced-motion`：直接呈现终态。页面不可见时停止。
- 不改动几何输出，动效只是同一真值的视觉过渡。

### 4.4 微交互

- 任务打勾印章动效（2.3）、修复应用后纸屑轻落（≤12 个 SVG 碎片，600ms，可随设置关）。
- 不做：全站视差、鼠标跟随、循环背景视频。
