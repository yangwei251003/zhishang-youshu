# 纸上有数｜V2审查与第三版迭代方案

审查日期：2026-09-27。对象：本项目 v0.2.0；本机生产构建 http://127.0.0.1:5191（独立端口，未触碰 5187/5189）。作者：WorkBuddy 小助。**本轮仅体验、审查、调研和撰写方案，没有实施第三版、修改产品代码或公开发布。**

阅读顺序：本文 → [V3设计与开发规格](02-V3设计与开发规格.md) → [竞品对标分析](03-竞品对标分析.md) → [多场景推演验证](04-多场景推演验证.md) → [架构评审](05-架构评审.md)。下一开发对话使用 [交接提示词](06-给codex的开发提示词.md)。

## 一、整体评估结论

**V2 是一个工程质量超出预期的学习闭环：预测门槛、留/剪目标标记、修复对照、拒绝草稿、学习记录、打印模板全部真实可用，视觉体系（朱砂窗花·素纸工坊）已经形成辨识度。但它目前更像"一座安静的实验室"，还不像"一间让人愿意坐下来剪一下午纸的工坊"。第三版要补齐三块：①把一次性的六步漫游升级为任务式新手引导，让新手真正走完"预测→折剪→展开→找问题→修复→迁移→打印"的完整循环；②扩充教学素材与实剪视频，让网站同时是"数字剪纸体验馆"和"现实剪纸启发站"；③加入剪纸音效与可选轻音乐，把沉浸感从"视觉层"推到"感官层"。同时修复本轮实测发现的 2 个缺陷和一批健壮性隐患。**

定位依据不变：面向成年剪纸初学者、高校通识课程和手工社团，验证"操作与解释是否帮助用户理解对称、孔洞与连通，并能迁移到新任务及实物"。第十四届数媒竞赛（CMIT 2026）报名与作品提交截止 **2026-10-23 23:59:59**，当前距截止约 26 天，V3 是功能冻结前的最后一个开发版本，须为真人试用与参赛材料留出至少 7–10 天。

本轮方法：精读全部源码（src 约 2470 行）与 V2 全部文档；在隔离浏览器真实走查——完成六步引导全程（含真实拖拽剪切、参数修改）、"留住这一线"修复全流程（3 个候选→80% 对照→应用→记录）、打印模板双页、非法剪口拒绝草稿、迁移题预测门槛、390×844 移动布局；采集控制台错误、字体加载与性能数据；随后全网调研 7 个同类作品、赛事评分要求、引导库与音频/视频素材合规来源。证据见 [evidence](evidence/)。

边界：代理模拟走查，不是真人试用；未真机触控、未实体打印实剪、未测低网速与存储耗尽。目录外其他项目未读取、未操作。

## 二、V2 版本核心亮点（必须保留，不得推倒）

1. **学习闭环的"诚实性"是最大资产。** 预测前不渲染结果、迁移题不提前给解法、提示计入"有辅助"、修复建议全部重算完整剪切序列、打印页明确"不保证实物牢固"。这种不吹牛的真实性在参赛答辩中是加分项，任何 V3 改动不得削弱。
2. **修复对照体验已是全场最佳。** 实测"第2剪收窄至80%"候选展示"原方案3片→修改后1片"、面积变化 616mm²、孔洞 2 个，并提示"需要用新纸制作"（证据 10-repair-compare.png）。
3. **留/剪目标标记把隐藏评分变成了可见任务。** 折叠态与展开态同图联动（证据 06-tour-step4-unfold.png）。
4. **拒绝草稿机制把报错变成了可修正的线索。** 虚线草稿＋持久行内错误（证据 13-rejected-draft-canvas.png）。
5. **打印模板是完整的"从屏幕到手心"交付物。** 双页：展开参照＋100mm 标尺＋折叠态刀线＋制作顺序＋剪切记录＋人工核对空栏（证据 11-print-template.png）。
6. **视觉体系已立住。** 朱红团花 hero、单元纹样、六阶段图标、纸感底色，移动端布局已合格（证据 01、15）。

## 三、本轮新发现的问题（V2 遗留）

### P0-11｜生产环境 CSP 阻断内联字体，首屏 6 个控制台错误

- **事实：** `scripts/serve.mjs` 的 CSP 为 `font-src 'self'`，但构建产物 CSS 中含 6 个 `data:font/woff(2)` 内联字体（vite 对小体积字体子集的默认内联），首屏全部被 CSP 阻断。`document.fonts` 共 101 个子集、仅 12 个加载成功，被阻断子集对应的字符回退系统字体，标题与正文实际字体表现不一致。证据：console-errors-fonts-csp.log、walkthrough-notes.json。
- **影响：** 评委打开控制台即见 6 条红色错误；字体渲染不一致损害"素纸宋体"的精心排版。V2 生产验证脚本统计的是"外部请求失败"而非 CSP 控制台错误，所以此前未暴露。
- **方案（二选一，推荐前者）：** ① serve.mjs CSP 改 `font-src 'self' data:`（一行，顺便同步 dev/preview 的任何 CSP 处）；② `vite.config.ts` 设 `build.assetsInlineLimit: 0` 让字体全部走文件。改后须重跑 `verify:production` 并把"控制台 0 错误"加入断言。
- **成本：** 极低，0.1 人日。

### P1-11｜引导卡片在中等宽度视口遮挡操作目标

- **事实：** 卡片定位 `left = max(12, rect.left − 342)`。约 1035px 视口（评委笔记本+投影缩放后极常见）下，预测面板左缘 x=233 < 342，卡片落到 x=12、宽约 330px，**完全遮住 A/B/C 选项文字**（证据 03）；引导第 5 步时卡片同样压住参数弹窗左半（证据 07）。1440px 下正常，390px 走窄屏布局正常，问题集中在 750–1300px。
- **影响：** 新手在引导最关键的一步（做预测）看不见选项；演示现场若用缩放或中屏会复现。
- **方案：** 卡片定位增加"避让目标"策略：目标为右栏/弹窗时优先放在目标下方流内位置；空间不足时把卡片改为底部停靠（与窄屏同一策略）；加一条 1100×800 视口的引导回归断言。
- **成本：** 低，0.25–0.5 人日。

### P1-12｜中屏（751–1100px）下预测入口仍需长滚动

- **事实：** 该断点右栏移到画布下方，"留住这一线"进入后预测面板在首屏之外（证据 09）。V2 已修手机端，中屏是遗留夹缝。
- **方案：** 中屏断点把"当前任务/预测卡"提升到画布之前（与 ≤750px 同序），或至少在画布区保留"去预测"定位按钮（该按钮已存在于占位卡，复用即可）。
- **成本：** 低，0.25 人日。

## 四、第三版三大主题（对应用户三个诉求）

### 主题 A｜任务式新手引导："纸上第一课"

**现状问题：** 六步漫游是"一条线"：讲完即走，不覆盖"找问题、修复、迁移"三个核心环节；每步只有两句说明，没有解释网站的文化内涵（为什么剪纸＋几何、什么是正形/负形、"留白"的意义）；中途退出后重看只能从头开始；完成没有仪式感也没有下一步指引。

**V3 方案：升级为"任务栏＋分幕引导"的双层结构（详细规格见 02 文档第 2 节）：**

1. **新手任务栏（Checklist）**：常驻左栏顶部（手机为可折叠卡），7 个任务对应完整学习循环：
   认识工坊（30 秒导览）→ 留下第一次预测 → 剪下第一刀 → 看纸展开 → 读懂一个问题（分离诊断）→ 修好它（应用一次修复）→ 带到纸上（打印纸样）。每完成一项打勾＋轻量庆祝（印章"已成"动效），全部完成获得"出徒"状态并把任务栏收成一枚"已出徒"印章。进度持久化在本机（与作品 JSON 分离的独立偏好键），老手一键"跳过全部"。
2. **分幕引导内容重写**：每幕讲清"做什么、为什么、和真实剪纸的关系"。例如"找问题"一幕：用"留住这一线"的真实 3 片结果，指出"第 2 刀切断了连接——在真实剪纸里，这一刀会让窗花散架"；"迁移"一幕说明"换一道没见过的题，检验你是真懂还是背下来"。文化内涵首次进入引导：一句话说明剪纸是联合国人类非遗、几何是它的骨架。
3. **断点续导**：任务栏状态即断点，重开引导从未完成任务继续。
4. **老手路径**：欢迎卡保留"直接进入，不再提示"；任务栏对已完成/已跳过设备默认收起。

**为什么这是 V3 的 P0：** 评委和首用者是同一类"第一次接触、没人讲解"的用户。本项目最大的认知门槛不是操作，而是"理解这个网站在教什么"。任务栏把 7 步循环显性化，本身就是对作品内涵的演示。

### 主题 B｜内容扩容与实剪视频："从数字到真实"

**现状问题：** 8 个课时（6 案例＋2 迁移）全部围绕"三角/矩形剪口＋2/4/8 折"，图案抽象；没有真实剪纸纹样（雪花、团花、蝴蝶、双喜、二方连续）；没有任何现实剪纸的影像内容；折法缺真实剪纸最常用的**六折（三角折/六角团花）**。

**V3 方案（规格见 02 文档第 3 节）：**

1. **新增"经典纹样"系列 4–6 课**（按实现成本排序）：
   - 六角雪花（需新增 6 折折法——**这是 V3 最大的一块几何工作**，内核 reflectPaths 增加 60° 旋转族即可，工作量可控但要补全套测试与打印模板折纸说明）；
   - 双喜字（矩形剪口组合，4 折，文化辨识度极高）；
   - 蝴蝶对折（2 折，正负形教学的最佳载体）；
   - 二方连续花边（4 折＋平移概念入门）；
   - 自由团花挑战（8 折，给定目标图案反推剪法的"看图还原"玩法）。
   若时间紧张，六折可砍，但**双喜和蝴蝶必须先上**——它们回答"案例是否典型有趣"。
2. **新增 2–3 道迁移新题**，与已有两题同规格（先预测、独立修复、提示计辅助）。
3. **实剪视频模块"纸上成真"（核心创新点）：**
   - **素材策略（2026-09-28 用户决策）：以产品完整性与体验质量为先，允许引入第三方优质剪纸教程视频与素材**，含：网上公开的经典剪纸教程（折纸手法、入刀角度、展开瞬间、经典纹样教学）下载到本地 `public/videos/` 使用；第三方素材在站内统一标注来源与原作者，建立 `docs/content-sources.md` 逐条登记出处链接。
   - 站外引用优先"可嵌入的官方播放器/公开页面"（不下载），下载仅用于无法嵌入但教学价值高的内容；站内自拍实剪仍作为 V3 后期的内容主线（最贴合"屏幕上的这一刀在真纸怎么剪"），第三方视频负责把"现实剪纸的丰富性"立刻撑起来。
   - 站内呈现：每课详情页一个"看真人怎么剪"小窗（默认不自动播放、默认无声），自由创作完成页出现"你的图案可以这样落到纸上"；另设"剪纸灵感库"栏目聚合经典纹样教程，让网站同时是"数字剪纸体验馆"和"现实剪纸启发站"。
   - 若日后重新考虑参赛，内容来源登记可直接用于替换/清理不合规素材。
4. **纹样素材库（装饰层）**：为经典纹样课绘制原创 SVG 纹样（延续 V2 母纹样语言），装饰素材与几何真值分离的原则不变。

### 主题 C｜沉浸感："听得见的剪纸"

**现状问题：** 全站零声音、动效克制到近乎静止；长时间使用时情感连接弱。用户明确要求考虑轻音乐。

**V3 方案（规格见 02 文档第 4 节）：**

1. **剪纸音效（默认开，可关）**：落剪"咔嚓"、展开"纸张摩擦"、成功"轻叩印"、拒绝"钝声"。用 Web Audio 合成或 ≤20KB 的授权音效文件；剪的时候有声音反馈，是沉浸感性价比最高的一项。
2. **环境轻音乐（默认关，一键开）**：右上/设置里放一枚"熏香"式开关，1–2 首循环纯音乐（古筝/笛/钢琴，-25dB 左右极低音量）。音源选择以品质为先：耳聆网、淘声网、Freesound、FreePD、Musopen 等公开素材站均可选用，逐条把来源链接与作者登记进 `docs/content-sources.md`；或用 Web Audio 生成式环境音。**绝不自动播放**（浏览器策略＋使用礼仪），尊重"减少动态效果/静音"偏好。
3. **展开动效增强**：分步展开时在折叠态→展开态之间做 300–500ms 的镜像生长过渡（SVG transform，尊重减少动态偏好），让"镜像"这个知识点多一种感知通道。
4. **微交互**：任务打勾的印章动效、修复应用的"纸屑轻落"粒子（极少量、可关）。

### 主题 D｜健壮性与参赛防备（防患清单）

## 五、其他值得做的增强（按价值/成本排序，非必须）

1. **学习进度总览页**：四单元掌握度（已完成课/迁移题独立通过数）、我的出徒之路——评委演示时 30 秒讲清作品的教学闭环。中价值中成本。
2. **"看图还原"挑战模式**：给一个展开后的目标纹样，反推折法与剪口。玩法上最"游戏化"，但要新的目标判定（图案相似度），成本高，可只做一个固定关。
3. **作品分享卡**：导出一张带作品图案＋名称＋"我在纸上有数完成的"的 PNG 分享图（canvas 合成，纯本地），利于传播与展览。低成本。
4. **教师打印包**：一键打包全部课时的学生页＋答案页 PDF。任务书 P1 原有项，参赛"教学价值"叙事的强证据，中成本。
5. **暗色模式**：与纸感美学冲突，**不建议**。
