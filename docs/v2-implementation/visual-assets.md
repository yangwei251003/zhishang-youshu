## 布局与可读性

- 主纸底 `#F5EFE3`，内容纸面 `#FFFCF5`，正文 `#302821`，次要文字 `#6B5748`，朱砂 `#B72D24`，靛青 `#355B61`。
- 主体正文及操作标签 14–16px；核心预测 16px；尺寸与图例辅助说明 12–13px；保留宋体标题及少量数字层级。背景不使用玻璃、光晕、粒子。
- 桌面双画布列下限 280px，目录 190px，观察 250px；可用宽度不足时把观察放到下方，再把目录放到画布前。窄屏使用全宽绘制 / 展开标签，不继续并排压缩输入区。
- 手机目录默认收起由 App 负责；预测未提交时反馈区先于画布；预测卡全宽。主输入触控控件目标 44px，键盘采用 3px 靛青焦点。
- 错误草稿说明为持久行内反馈；参数预览 SVG 高 220px；目标图例换行，目标行可定位。几何验收由现有计算流程负责。
