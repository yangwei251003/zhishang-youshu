## 如何体验

本地第二版入口：http://127.0.0.1:5189 。双击项目根的`启动第二版.cmd`可重新启动已构建版本。开发与全量测试使用5188；原5187服务没有停止或替换。原5187当前返回旧资源入口，不能把它当作第二版验收页面。

**不同端口的浏览器作品库互相隔离。** 旧版作品可在5187导出项目JSON，再在5189导入；V1项目格式仍受支持。这里不声称已读取或迁移用户实际浏览器中的作品。自动验收在隔离浏览器内恢复旧格式项目和真实存档。

## 实施中发现并修正

1. 原App快照SHA256与审查快照一致（F8D1729B…03F775186），仓库仍无初始提交；没有重置或覆盖用户Git提交。改动基于当前工作树，版本不虚构HEAD。
2. 迁移的提交后解释与打印也可能指认答案，因此门槛扩至提示状态；B0/E1方法已追加V2规则。
3. 引导遮罩曾拦截程序下载链接，现只放行具download属性的blob下载；真实下载断言保留并复测。
4. 固定手机滚动偏移会把题干滚出视口，现按提示卡与目标实测矩形定位；题干和画布均在提示卡上方实测。
5. 并行浏览器测试曾争用默认test-results目录导致ENOENT。已隔离输出目录；最终全量测试使用单次统一运行。不将该工具附件冲突归为产品失败。
6. 旧生产验证脚本在欢迎框出现前判断可见性，有竞态；改为等待并点击真实欢迎按钮后测试。没有删除原验证断言。
7. 最终生产复查捕获撤销后“已自动保存”旧状态短暂残留，立即刷新会恢复旧版本。已把保存请求失效与pending状态前移到updateDocument同步阶段，手动保存也核对快照版本，避免旧请求回写新状态；保留真实刷新断言并重新验收。
8. 手机手动展开目录后切课曾继续展开；切换成功后显式收起窄屏目录，并补入生命周期验收。
