# 第四版审查包（产品化打磨方案）

日期：2026-09-28。对象：本项目 v0.3.0（第三版）。本轮由 WorkBuddy 小助执行：**核对第三版实施成果、真实运行生产构建逐项复现用户反馈的 5 个问题、量化根因、产出第四版规格与开发提示词。没有修改任何产品代码与既有文件。**

阅读顺序：

1. [V3审查与第四版优化方案](01-V3审查与第四版优化方案.md)：完成度核对、5 项反馈的根因与优先级、执行清单。
2. [主题系统设计规格](02-主题系统设计规格.md)：256 个硬编码颜色的收敛方案、5 套剪纸主题、对比度守卫、圆形涟漪切换动效。
3. [音频系统设计规格](03-音频系统设计规格.md)：多曲目播放器、响度归一化、音量控制、素材来源。
4. [布局与导航修复规格](04-布局与导航修复规格.md)：首页留白、导航激活态、移动端头部、视频本地化。
5. [P2开发评估](05-P2开发评估.md)：四项 P2 逐项裁决（进度总览与分享卡做、看图还原只做 MVP、教师包延后），并附"六折为何不做"的代码级论证。
6. [给codex的开发提示词](06-给codex的开发提示词.md)：复制全文即可交接。

关键结论：**第三版的功能骨架已经完整（103 单测全通过、控制台 0 错误、七任务引导/灵感库/音效都已落地），本轮的 5 项反馈全部是"最后一公里"的产品质感问题，且都能定位到唯一根因——中栏 ~690px 空白源于 Grid 强制等高（驱动行高的是左栏，不是右栏）；导航不切换源于写死的 `className="nav-active"`；音乐听不见源于 −34.1 dBFS 的链路增益（比音效低约 18–20 dB）；主题切换受限源于 281 处硬编码色值。**

> ⚠️ 读 `01` 时的修正提示：该文档早期把首页留白的元凶记为"右栏实剪视频卡（553px）太高"。**复测后已修正**：右栏自身只用到 1218px、同样留白 476px；真正驱动整行高度的是**左栏**（1694px，其中 `.apprentice-tasks` 564px + `.lessons-section` 543px）。完整数据与修正后的根因见 `04` §1 与 [evidence/measurements.json](evidence/measurements.json)。**任何只改右栏的方案都不会解决这个问题。**
