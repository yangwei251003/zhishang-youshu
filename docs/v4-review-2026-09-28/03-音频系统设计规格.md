# 纸上有数｜音频系统设计规格（V4）

状态：2026-09-28 审查后的待实施方案。用户反馈原话："音频声音太小了，我电脑放到最大声了都听不见音乐，音乐请 codex 到时找多几首然后爬取下来然后可以让用户选择。"

## 1. 现状与根因（已量化）

|项|现状|问题|
|---|---|---|
|音乐实现|`src/audio/sfx.ts` 的 `setMusic()`，**代码合成的单条 16 音五声音阶乐句**，每 1350ms 发声一次|只有一首、固定不变，无法选曲|
|音乐总增益|`bus.gain = 10^(-25/20) = 0.0562`，单音 level 0.35|**实际峰值 ≈ 0.0197 = −34.1 dBFS**|
|低音支声|110Hz，level 0.15|**≈ −41.5 dBFS**|
|对照组：落剪音效|level 0.16|≈ −15.9 dBFS，**比音乐高约 18–20 dB**|
|本地音频文件|`public/` 下 **0 个**|无素材可换、离线无音乐|
|音量控制|无|用户只能靠系统音量，而系统音量拉满仍听不见|
|状态机|`aria-pressed` + `localStorage` 正常|逻辑无问题，纯音量与内容问题|

**结论**：−25 dB 的设定写在按钮 title 里（"约 −25 dB"），本意是"极轻的环境音"，但叠加单音电平后实际只有 −34 dBFS——这是设计意图与实现效果的偏差，不是 bug。修正方向不是简单调大，而是**改为标准响度体系的真实曲目 + 用户可控音量**。

## 2. 目标

1. **默认音量下清晰可闻**：不调系统音量、不调应用音量，第一次点开就能听见；
2. **多曲目可选**：≥4 首，风格统一（中国风器乐／空灵氛围），可切上一首/下一首；
3. **音量可控**：滑块 0–100%，默认 60%，记忆偏好；
4. **不吵、不打断**：环境音定位不变，最大音量也不盖过音效与操作反馈；
5. **离线可用**：全部本地文件，断网照常播放。

### 3.2 获取方式（按用户授权：可从公开站下载）

1. **候选来源**（任选，优先能试听且注明可自由使用的）：
   - 耳聆网 `ear0.com`（国内，中文器乐多，逐条标注授权）
   - 淘声网 `tosound.com`（聚合检索，按情绪/风格筛选）
   - FreePD `freepd.com`（CC0，免署名）
   - Musopen `musopen.org`（公共版权古典）
   - Freesound `freesound.org`（音效与短曲）
2. **推荐检索词**："古筝 纯音乐"、"竹笛 轻音乐"、"中国风 背景音乐"、"guqin ambient"、"chinese traditional instrumental"、"meditation guzheng"。
3. **选取标准**：无人声、无强节奏鼓点、无突然的强弱跳变（避免打断注意力）、loop 友好（首尾自然）。
4. **下载与转码（推荐统一命令）**：

```bash
# 1) 响度归一化到流媒体标准 −16 LUFS，真峰值 −1.5 dBTP
ffmpeg -i source.mp3 -af "loudnorm=I=-16:TP=-1.5:LRA=11" -b:a 160k -ar 44100 public/audio/zs-track-1.mp3
# 2) 裁到 2–4 分钟并做 2 秒淡入淡出，便于无缝循环
ffmpeg -i zs-track-1.mp3 -af "afade=t=in:d=2,afade=t=out:st=170:d=3" -t 175 public/audio/zs-track-1.mp3
```

单曲 ≤4MB（160kbps ≈ 3.5MB/3分钟）；全部放 `public/audio/`，命名 `zs-track-{1..4}.mp3`，并同时生成 `-cover.svg`（用主题色绘制的唱片封面，避免用第三方图片）。
5. **登记**：在 `docs/content-sources.md` 增加"音频"章节，逐条记录曲名、作者、来源 URL、获取日期、许可标注、转码参数。**站内播放器旁展示"曲名 · 作者/来源"**。

## 4. 播放器设计

### 4.1 顶栏入口

- 现有两个按钮保留：`音效开/关`（图标 `Volume2`/`VolumeX`）、`轻音乐`（图标 `Music2`）。
- "轻音乐"按钮点击行为改为：**未播放 → 直接播放上次选中曲目（默认第 1 首）；播放中 → 展开播放器面板**（不再是一键关闭，避免误关）。
- 面板内提供明确的"暂停/停止"。

### 4.3 音量与响度

|项|规格|
|---|---|
|素材响度|统一归一化到 **−16 LUFS**（真峰值 ≤ −1.5 dBTP）|
|默认音量|**0.6**（相对增益，非 dB 数值直传）|
|音量范围|0–1，滑块步进 5%，显示百分比|
|最大音量|1.0，但仍不得盖过音效（音效走独立 gain，见下）|
|音乐总线|`musicGain = 0.6 * 用户音量`，直接接 `destination`|
|音效总线|新增 `sfxGain`，默认 **0.8**，独立滑块（可放在同一面板的"音效"分区）|
|静默保护|音量 >0 但用户设为 0 的边界要正确（0 即静音但不停止播放状态）|

实现要点：删除 `Math.pow(10, -25/20)` 这类固定 dB 降幅，改为"素材本身是按 −16 LUFS 归一化的成品，播放增益只由用户滑块决定"。原来的 −25dB 设计只保留在"生成乐句"这条备选曲上（它的电平本来就低，作为"更轻"的选项合理）。

### 4.4 行为细节

- **手势启动**：保留现有 `installAudioGestures()`——首个可信手势后才创建 `AudioContext`；
- **默认关闭**：仍是默认 `music: false`，用户主动开启才播（避免自动播放被拦截）；
- **切页不中断**：从工坊切到灵感库、打开弹窗、切换主题，音乐继续；
- **标签页隐藏**：`visibilitychange` 暂停播放；回到页面时**在按钮上显示"已暂停"状态**（遵守"不自动播放"原则，用户点击继续）；
- **加载失败**：某曲 404/解码失败 → 该曲标灰并提示"这首暂时不可用"，自动跳到下一首；全部失败 → 自动回落到"生成乐句"备选，音乐功能永不假死；
- **切曲过渡**：150–250ms 交叉淡出淡入，避免爆音；
- **不播第二路**：同一时刻只有一路音乐，切曲先停旧再起新。

## 5. 状态与持久化

```ts
// 键：paperWorkshop.audio.v2
{ sfx: boolean, sfxVolume: number, music: boolean,
  trackId: string, volume: number, loop: 'one' | 'all' }
```

- 从 v1（`{sfx, music}`）**平滑迁移**：读取 v1 → 映射为 v2 默认（trackId='zs-track-1'，volume=0.6，loop='all'）→ 写回 v2；v1 保留不删，便于回滚；
- 存储不可用时退化为会话内（沿用现有 `StorageNotice` 提示机制，不新增弹窗）。

## 6. 与主题系统的关系

- 播放器面板、滑块、色卡等**全部使用主题 token**，深色主题下不出现"白面板+亮滑块"的割裂；
- 曲目封面用 `currentColor`/token 绘制（SVG），随主题变色；
- 音量滑块轨道/填充使用 `line` / `brand` token。

- [ ] 音量滑块 0–100% 生效并记忆；静音后恢复不跳变；
- [ ] "生成乐句"备选曲仍可使用（离线绝对可用）；
- [ ] 断网状态下 4 首本地曲目正常播放（无任何外部请求）；
- [ ] 标签页隐藏暂停、回到页面显示"已暂停"且不自动续播；
- [ ] 冷启动 0 外部请求、0 未捕获异常；无用户手势时不创建 AudioContext；

- [ ] 所有曲目在 `docs/content-sources.md` 登记，播放器内展示曲名与来源；
- [ ] 音效与音乐音量互不干扰；关闭音乐不影响音效。
