# 纸上有数｜主题系统设计规格（V4 核心）

状态：2026-09-28 审查后的待实施方案。配套证据：[theme-contrast-report.txt](evidence/theme-contrast-report.txt)、[theme-contrast-check.mjs](evidence/theme-contrast-check.mjs)（可直接复跑校验）。

## 0. 为什么必须先做色板收敛

现状：`src/styles.css` + `src/styles/media.css` 共 **281 处硬编码色值、256 个不同颜色**，`:root` 只有 10 个变量。

如果直接叠一层"换背景色"，必然出现用户最担心的四类问题：对比度崩塌、色彩数量失控、品牌色漂移、交互态（hover/active/disabled/focus）与新背景打架。**因此主题化的第一步不是加主题，而是把 256 个色值收敛成一套语义 token；这一步做完，加主题才只是"换一组数值"。**

## 1. 语义 Token 清单（34 个，分 8 组）

命名一律 `--zs-*` 前缀，避免与现有短变量冲突；旧变量（`--paper/--ink/--red` 等）保留 alias 指向新 token，减少一次性改动风险。

|组|token|用途|约束|
|---|---|---|---|
|背景层|`--zs-bg-canvas`|页面最底（`.app-shell`、`body`）|与 `bg-paper` 需有 ≥1.05:1 层次|
||`--zs-bg-paper`|纸面／卡片／弹窗／栏底|正文承载面，最高对比基准|
||`--zs-bg-sunken`|画布底、凹陷区（`.artboard`、输入框底）|略深于 canvas|
||`--zs-bg-overlay`|遮罩（现有 `#302821d9` 类）|固定 55–62% 不透明墨色|
|文字层|`--zs-text-primary`|正文、标题、关键解释|对纸面 ≥4.5:1|
||`--zs-text-secondary`|次要说明|对纸面/页底 ≥4.5:1|
||`--zs-text-muted`|辅助标注、来源、时长|对纸面/页底 ≥4.5:1|
||`--zs-text-on-brand`|主按钮文字|对 `brand` 与 `brand-strong` ≥4.5:1|
|边框层|`--zs-line`|分隔线（装饰）|对页底 ≥1.5:1|
||`--zs-line-strong`|控件边框、输入框、tab 底线|对纸面 ≥3:1（非文本）|
||`--zs-focus-ring`|键盘焦点轮廓|对纸面 ≥3:1|
|品牌层|`--zs-brand`|主按钮底、当前主操作|填充色|
||`--zs-brand-strong`|按下/hover、重点描线|填充色|
||`--zs-brand-soft`|品牌浅底（选中行、提示条底）|承载正文仍需 ≥4.5:1|
||`--zs-brand-text`|正文中的朱砂强调（链接、修复建议）|对纸面/页底 ≥4.5:1|
|辅助语义|`--zs-accent-info`|靛青：目标"留"标记、信息辅助|对纸面 ≥4.5:1（文字用法）|
||`--zs-accent-warm`|赭石：装饰、序号|对纸面 ≥4.5:1|
||`--zs-success`|通过态（勾选、"已成"印章）|= `accent-info` 或独立，须 ≥4.5:1|
||`--zs-warn`|警示（"待检查项"）|≥4.5:1|
||`--zs-danger`|拒绝/错误（剪口被拒）|= `brand-text` 语义，但可独立调色|
|交互态|`--zs-hover-bg`|悬停底|与 `bg-paper` 可辨但不刺眼|
||`--zs-active-bg`|按下/选中底|同上，略强|
||`--zs-selected-border`|选中项边框|= `brand` 或 `brand-strong`|
||`--zs-disabled-bg`|禁用底|与纸面可辨 ≤1.4:1（不可抢眼）|
||`--zs-disabled-text`|禁用文字|不参与 4.5 阈值（非可读要求），但 ≥3:1|
||`--zs-ghost-hover`|图标按钮悬停底|低强度|
|画布专用（**关键：随主题调整**）|`--zs-canvas-retain`|保留的纸（红纸主体）|对纸面/页底 ≥3:1（图形）|
||`--zs-canvas-cut`|裁去的空白|通常 = `bg-paper`|
||`--zs-canvas-grid`|毫米网格点|低强度、不干扰几何|
||`--zs-canvas-fold`|折线（灰虚线）|可辨但不抢刀线|
||`--zs-goal-retain`|"留"标记|对纸面 ≥3:1|
||`--zs-goal-cut`|"剪"标记|对纸面 ≥3:1|
|阴影|`--zs-shadow-card` / `--zs-shadow-dialog` / `--zs-shadow-float`|三级投影|深色主题下改用"底部暗晕＋顶缘微亮"，不要纯黑投影|

**收敛方法（可机械执行）**：把 256 个色值按用途归类 → 每类取中位数色 → 覆盖到 token；无法归类的按"是否文字/边框/背景"就近合并；最终目标：`styles.css` + `media.css` 中**除 token 定义块外，硬编码色值 ≤12 处**（仅允许出现在纹样 SVG 内联与打印页固定样式）。

**深色主题的两条设计规则（本轮实测得出）：**
1. **品牌填充不能太亮**：深色底上若用亮红做按钮底，白字只有 3.4–3.6:1。故深色主题按钮底取**深朱** `#C0392B`（配米白文字 4.98:1），按下态 `#A8321F`（6.12:1）。
2. **正文里的朱砂强调要比填充色更亮**：深色主题中文字强调改用 `#F08A72`（对纸面 6.72:1），否则 `#D9563E` 只有 4.19:1 不达标。即"填充"与"文字"在深色下需要拆成两个色，这是同一色相下的必要分化，不是色彩数量失控。

每套主题的**色相家族上限 = 3**（纸底／墨色／朱砂），靛青与赭石只作标记与序号辅助，不参与大面积铺色——这是"色彩数量不失控"的硬约束。

## 3. 对比度守卫（自动化，必须落地）

新增 `npm run check:contrast`：

- 输入：5 套主题的 token 表（单一数据源，建议 `src/theme/palettes.ts`，CSS 由该表生成或在测试中读取 CSS 变量解析）；
- 检查：正文/次要/弱提示 × {纸面, 页底}、按钮文字 × {brand, brand-strong}、朱砂强调、靛青、赭石 × 纸面、控件边框与焦点环 × 纸面、剪纸红纸与留剪标记 × {纸面, 页底}，共 **105 项**（已在本轮脚本中跑通，全部达标）；
- 阈值：正文/文字类 4.5:1，非文本元件与图形 3:1，装饰分隔线 1.5:1，层次 1.05:1；
- 输出：`docs/evidence/theme-contrast.md` 表格（本目录已先给出可复跑版本：[evidence/theme-contrast-check.mjs](evidence/theme-contrast-check.mjs) 与 [evidence/theme-contrast-report.txt](evidence/theme-contrast-report.txt)，当前 **105/105 全部达标**）；**任一项不达标，命令以非 0 退出**，接入 `npm test` 或 `verify:production`；
- 额外检查：每主题色相家族数 ≤3、token 数量恒定（防止主题之间"多塞颜色"）。

## 4. 圆形涟漪切换动效

**首选实现（View Transitions API）**：

```css
::view-transition-old(root), ::view-transition-new(root) { animation: none; mix-blend-mode: normal; }
::view-transition-new(root) { clip-path: circle(0 at var(--ripple-x) var(--ripple-y)); animation: zs-ripple 520ms ease-out forwards; }
@keyframes zs-ripple { to { clip-path: circle(var(--ripple-r) at var(--ripple-x) var(--ripple-y)); } }
```

```ts
const r = Math.hypot(Math.max(x, innerWidth - x), Math.max(y, innerHeight - y));
document.documentElement.style.setProperty('--ripple-x', `${x}px`);
document.documentElement.style.setProperty('--ripple-r', `${r}px`);
document.startViewTransition(() => applyTheme(next));
```

- `--ripple-x/y` 取**点击色卡的鼠标坐标**（涟漪从指尖扩散，用户感知最强）；`--ripple-r` 为到最远角的距离；
- 时长 420–600ms，`ease-out`；主题在快照切换瞬间完成，避免闪烁；
- **降级路径**（不支持 View Transitions 的浏览器）：自绘一层 `.theme-ripple` 固定覆盖圆（`position:fixed; border-radius:50%; pointer-events:none`），动画放大到覆盖视口后切换 `data-theme`，再 180ms 淡出；
- `prefers-reduced-motion: reduce`：**直接切换，无动效**；
- 动效期间禁用重复触发（切换中再点无效或排队一次），不可产生"半套主题"中间态。

## 5. 切换入口与持久化

- 顶栏新增"纸色"按钮（Lucide `Palette`），位于音频开关左侧；点击弹出小面板：**5 个圆形色卡**（每个色卡用该主题的 `bg-canvas` 底＋`canvas-retain` 剪纸红做预览）＋主题名＋"跟随系统"开关；
- 面板键盘可达（Tab/方向键/Esc），`aria-pressed` 标记当前主题，`role="radiogroup"` 语义；
- 持久化键 `paperWorkshop.theme.v1`：`{ mode: 'manual' | 'system', value: 'plain' | 'bamboo' | 'lacquer' | 'ink' | 'indigo' }`；
- "跟随系统"时监听 `prefers-color-scheme`：浅 → 素纸，深 → 玄墨；
- 存储不可用时退化为会话内（沿用现有 StorageNotice 机制提示）；
- 首访默认素纸，**不主动弹主题引导**，但可在"纸上第一课"任务 1（认识工坊）里提一句"右上角可以换纸色"。

## 6. 隔离原则（不可破坏）

|对象|是否跟随主题|说明|
|---|---|---|
|工坊界面|✅|全部 token 化|
|灵感库页面|✅|视频卡片、分类标签同步|
|画布几何（折剪/展开/标记）|✅（仅颜色）|深色主题下红纸提亮、留剪标记改用月白靛青；**几何真值与坐标永不变**|
|导出 SVG（艺术图样）|❌|固定白底红纸，保证通用|
|打印页 HTML|❌|固定白底黑线＋红纸＋100mm 标尺；打印样式单独硬编码，不读 token|
|作品分享卡（P2）|可选|导出时按当前主题渲染，但提供"标准配色"开关|
|装饰纹样 SVG|部分|纹样 fill 用 `currentColor` 或 token，随主题变色|
