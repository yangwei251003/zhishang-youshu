## 2. 学习流程、答案门槛与目标标记（P0）

### 2.1 最小任务状态

使用一份权威状态，避免在按钮、画布和打印处各写一套不同的条件。

|状态|允许看到/做什么|下一状态|
|---|---|---|
|自由创作|完整编辑、展开、保存、打印；无需预测|主动进入课程后新建学习尝试|
|进入任务|只展示中性题面、目标和操作说明|确认开始；写入attempt_start|
|待预测|折叠图、预设剪口、无答案的题面；备份可用|提交并持久记录预测|
|已预测/观察|显示结果、结构计数，允许修改、对照与展开|独立修改或主动请求提示|
|有辅助探索|保留探索工具，写入提示使用记录|结果按有辅助归档|
|目标通过|显示结构通过，邀请解释或记录屏幕实验|进入下一课/新题/导出|
|离开/中止|保存设计与尝试，不伪造完成|可继续该尝试或明确重新开始|

普通学习可以在提交预测后获得解释；迁移题在提交后可以看结果，但**第一次独立修复前不直接给出哪一刀的解法**。给“需要一点提示”明确入口，打开后转为有辅助。当前B0/E1实验规则需保持一致；如果改变条件内容，更新人工试验说明与版本后再采集新批次，不混用旧数据。

### 2.2 必须逐个关闭的答案旁路

在 `mode=learn && prediction未提交` 时统一检查：

1. 结果区域使用中性占位，不将展开路径、计数和错误步骤渲染到该区域再遮挡；避免半透明漏出轮廓。
2. 顶栏“打印纸样”、右栏“把实验带到纸上”、导出弹窗的SVG/A4入口、分步展开和上一刀对照均不可揭晓。按钮附近说明“先留下预测，再查看完整结果”，不能只有灰色禁用态。
3. 课程确认框与历史名称不得暴露正确答案；目标条目中可能透露孔数/结果的内容延后。
4. 待预测期间禁止修改题目几何、撤销或替换剪口，确保题面与首次预测针对同一版本。自由创作不受影响。
5. 切到自由创作保留离开记录；新建/重开/导入不能把看过结果的旧尝试再次标成未见答案。
6. 我的作品缩略图若新增，未作答学习项目只显示折叠图/统一封面。当前作品库无缩略图，不要求为此新增图库。
7. 项目JSON备份允许，包含原始几何不构成防作弊漏洞；本项目不是考试反作弊系统。目标是消除正常使用路径的泄露，不阻止用户读源码。

### 2.4 目标可见性

数据来源：`Lesson.goal.requiredRetained / requiredRemoved`，当前已有毫米坐标。渲染方案：

- “留”：深靛实心小圈＋编号，图例“这里需要保留纸”；“剪”：朱红空心叉圈＋编号，图例“这里需要剪去”。除颜色外保留不同形状与文字。
- 标记默认以屏幕像素固定大小显示，不随缩放变成巨大色块；覆盖位置保持可辨，悬停/焦点显示解释。
- 一行目标涉及多个点时标为“剪1、剪2”，点击该行依次定位/同时强调，不让开发者手填目标像素坐标。
- 折叠图与展开图使用同一毫米真值；按折法映射到折叠域，重复投影去重。只在当前教学阶段允许时显示展开标记。
- 失败例：“剪1还没有剪到。请让剪口覆盖标记处，再看看结构是否保持完整。”这是位置要求，不是自动修复答案。
- 工程性目标如“非空”“退化接触”折叠进“结构检查详情”；主列表保留2–3条教学要求，例如“纸连成一片 / 花窗还在 / 指定缺口已剪出”。不得删掉底层完整判定。
- 导出艺术SVG保持干净；打印正式模板保留已有刀线与标尺。若增加“讲解用图”，与制作模板分开命名，不覆盖它。

P0验收：复现第一课 X=77、宽3mm；界面仍正确判定未达标，并能明确指认“剪1/剪2”的位置。恢复原剪口后标记与判定同步，不改变原几何结果。

## 3. 首次进入与实景漫游（P1-01）

### 3.1 进入规则

本设备第一次且无恢复作品：短欢迎卡。已有作品但没有引导设置：直接恢复作品，用“第一次使用？带你走一遍”轻入口，不自动替换作品。已完成或已跳过：直接进入。

欢迎卡成稿：

> **一张纸，先想，再剪。**
>
> 先猜展开后的样子，再动手剪一刀，看看对称与连接怎样改变。最后，把你的实验打印到真实纸张上。
>
> 主按钮：带我完成第一剪
>
> 次按钮：直接进入，不再提示
>
> 小字：不用登录。作品保存在本机，也可以导出备份。

使用独立设备偏好，例如 `paperWorkshop.onboarding.v1`，字段限 `status: completed|skipped`、`tourVersion`。跳过立刻写入；主动重看不抹掉skip选择。存储不可用时仅当前会话记忆，不能阻断创作。升级小版本不能擅自再次强弹引导；清理浏览器数据后可能再次出现，说明这是本设备偏好。

### 3.2 六步实景高亮

欢迎不算一步。每步显示“1/6”、标题、一句目的、一句操作和“上一步 / 下一步 / 跳过且不再提示”。在实际操作完成前，不用“下一步”伪造成功；可提供“先看说明”跳过操作，但以演示而非独立完成归档。

|步|稳定锚点建议|界面文字与动作|验证|
|---|---|---|---|
|1 选一张纸|`data-tour="lesson-entry"`|“先从一课开始。我们用对折的小实验，认识左右对称。”选择独立练习副本|原作品先保存；已有作品不被覆盖|
|2 先想一想|`data-tour="prediction"`|“先留下你的判断。猜错也没关系。”高亮题目与选项|不预选答案、不报正确选项；提交后再进入结果环节|
|3 试着剪入|`data-tour="folded-canvas"`|“在纸边按下，向纸里拖，再松开。”纸边描线＋一次无答案示意手势|可用不影响正式题的练习纸；必须从当前真实边界进入|
|4 看纸展开|`data-tour="unfold-controls"`|“展开一层，看看这一刀出现在哪里。”高亮展开按钮与结果|调用现有展开阶段，不用装饰动画替代计算|
|5 回看一刀|`data-tour="history"`|“点一刀可以回看；选择‘调整参数’，再比较它的变化。”|未成功修改不显示已完成；可以返回当前设计|
|6 带到纸上|`data-tour="export"`|“保存能继续改，纸样能拿去剪。打印前先量100mm标尺。”|结束按钮“开始我的实验”；此步不自动发起打印|

降低实现量的方式：用一份独立引导练习副本承载上述操作，保留与正式课程同样的真实几何反馈。它的记录 `origin=onboarding`，不得作为正式首次预测或迁移效果。若复用第一课，下一步独立试用必须换材料，不把已学过的题当未见题。

### 3.3 蒙层和键盘规范

- 桌面提示卡宽约300–340px，高亮外扩8px；提示卡避开按钮、题干与画布，必要时滚动到目标后再定位。
- 使用ResizeObserver与滚动事件更新锚点位置；缩放/折叠面板/切换布局后重新计算。目标不存在或计算中时等待或跳到说明页，不能高亮屏幕原坐标。
- 一次仅一个高亮区域，背景遮罩墨色约50%透明。需要用户操作时目标区域可交互，周边不可误触；如果用模态语义，焦点范围必须包含当前步骤所需的操作区域，不让 `aria-modal` 排除真正可操作的目标。
- 纯讲解步骤可采用现有Dialog；实操步骤可采用非模态引导卡＋受控交互范围。不要只加Tab陷阱却让用户无法选预测答案。
- Esc与“跳过且不再提示”都能退出；关闭后焦点回到合理的操作入口。Tab/Shift+Tab可完成全部按钮与选项。
- 手机提示放在目标邻近的流内/底部说明区，确保不遮目标；不在103px旧画布上勉强挖洞。
- 尊重减少动态效果；取消滑动和示意手势，保留静态图与同样文字。
- 用户点击跳过时不重置作品、历史、折法或预测；引导偏好与作品JSON分离。

## 4. 视觉总方向：朱砂窗花·素纸工坊（P1-04/05）

目标不是“全站复古”，而是让“热烈中有含蓄，朴素中有精巧，喜庆中有深情”分别有可见落点：

|气质|具体呈现|避免|
|---|---|---|
|热烈中有含蓄|首屏一处醒目的朱红团花；工作区大面积素纸留白|满屏红、金、动态光晕争抢注意力|
|朴素中有精巧|少色、清楚的镂空正负形、细小锯齿/月牙装饰；图标与分隔统一切纸语言|所有按钮卡片都加纹样、毛边导致阅读噪声|
|喜庆中有深情|花叶、窗格、纸片与手作过程；文案“把这一纸，带回手心”|笼统宣称“千年非遗传承”或给原创纹样捏造地方历史|

以上纹样选择是当代设计建议，不能声称属于经考证的特定地域技法。UNESCO资料用于理解文化语境，不用于授权复制图片。

### 4.1 色彩与文字

建议token（实施时对真实叠加背景重新测量）：

|用途|颜色|规则|
|---|---|---|
|主纸底|`#F5EFE3`|大面积安静背景|
|内容纸面|`#FFFCF5`|正文、弹窗、表单|
|墨色正文|`#302821`|主要解释，不做半透明|
|次要文字|`#6B5748`|保证在纸底上仍清楚|
|朱砂主色|`#B72D24`|当前主操作、主要纸张、品牌插画|
|深朱红|`#8F241D`|按下状态、重点描线|
|赭石|`#A97942`|只作少量装饰，不默认用作小字|
|靛青辅助|`#355B61`|目标“留”标记、信息辅助|
|分隔线|`#D8C8B1`|用于分区，不独立承担可操作提示|

标题沿用已本地化的Noto Serif SC，适度用宋体气质；正文采用现有系统中文无衬线，避免全文极细宋体。H1桌面36–44px、手机28–32px；区块标题18–22px；正文14–16px；核心教学解释16px；辅助标注12px。行高正文约1.7，数字与尺寸采用等宽数字。英语小字只在必要处保留，不以大面积英文小标题营造质感。

正常文本对比度≥4.5:1，大号文字≥3:1；核心交互轮廓/焦点在背景上可辨。触控目标建议44px，这是本产品的设计目标；不误称WCAG2.2所有目标都必须44px。

### 4.2 背景、插画和图标的分工

1. **最底层：**暖纸纯色，加载失败仍成立。
2. **纸感层：**一张本地小尺寸可平铺纹理或简单SVG纹理，不透明度约2%–4%，放在首屏/边缘，不覆盖阅读正文与真实几何区域；不要用每帧重算噪声。
3. **文化层：**原创团花、花叶剪影、局部窗格。首屏最多一组主视觉，侧边装饰只在不抢画布的位置出现；手机裁去装饰，不裁关键信息。
4. **内容层：**干净纸面与明确边框，纸片式1–2层轻投影；工具区不使用玻璃透底，不给每张卡片做厚阴影。
5. **反馈层：**被选中剪口、必留必剪标记、错误草稿的颜色与线型优先于装饰。

通用保存/打印/关闭图标继续采用现有Lucide，避免为“传统感”牺牲识别。六阶段/四单元可以自绘SVG，保持24px基础网格、适度粗细和清楚轮廓；不要用表情符号代替专业图标。

### 4.3 桌面信息布局

首访“欢迎”是工作台入口，不另建一个很长的营销网站。推荐布局：

```text

└ 首次展开；熟悉用户收起为一行提示 ───────────────────┘
作品名称 / 自动保存状态 / 新建 / 导入 / 保存与导出
┌ 课程与工具 ┬ 当前任务、当前阶段 ───────────┬ 本步观察 ┐

│ 目录可收起 │ 不低于280px    视觉结果适度大   │ 预测/目标 │
```

如果1440px下无法同时容纳上述最小宽度，先收起课程目录，再收起次要观察，不压缩绘制区。首屏品牌介绍高度建议140–200px；进入实验后收起至短条，避免为装饰让核心操作长期低于首屏。大展开图仍是成果焦点，但不再挤压输入画布。

### 4.4 手机和中屏

- ≤750px：当前实验/换一课 → 当前任务或预测 → 绘制/展开标签 → 画布 → 本步反馈 → 历史。不要把全部课程目录默认铺满首屏。
- 390px宽、两侧各16px后，画布尽量使用可用宽度；验收底线280px。预测卡全宽，不与纸张寄语卡并排。
- 751–1100px：目录可收起，观察区放画布后但紧邻当前操作；不保留错误的“右侧”提示。
- 360px最低布局也应检查。桌面200%缩放时按可用CSS宽度进入相应断点，不能靠缩小字适配。

|`paper-grain`|首屏/空白边缘|小纹理，目标≤40KB|无明显重复网点，正文对比度不下降|
|作品空状态插画|没有存档时|复用“半张纸＋剪刀＋一片花叶”|明确“新建实验”，不伪造用户作品|
|可选片头插画|短介绍封面|WebP/AVIF，1600px左右，目标≤250KB|标注AI装饰示意，不能作为实剪证明|

文件名只是建议，素材都放本项目内。首轮优先原创SVG，图片可选；**不要求联网素材库或引入外部字体**。新视觉资源的传输体积先以≤350KB作为预算目标，实施后记录真实体积，不把目标写成实测结果。

## 5. 控件状态与反馈规范

|状态/场景|具体呈现|行为|
|---|---|---|
|悬停|暖纸底微变、深朱边框；最多1px轻位移|画布不随鼠标浮动|
|按下|主按钮深朱色，轻微压纸感|不做弹跳和长动画|
|键盘焦点|2px清楚轮廓，外扩2–4px|可见且不被蒙层挡住|
|禁用|对比适当降低＋近旁说明原因|不能用无法聚焦的tooltip作为唯一解释|
|计算中|局部“正在检查这一刀”及小指示|不把旧通过结果当新结果；结束后状态同步|
|成功剪切|画布更新＋“第N刀已应用”短反馈|不每刀弹阻断对话框|
|失败剪切|保留虚线草稿＋行内错误＋相关纸边强调|历史/当前图保持原样；可重画/清除|
|目标不通过|对应目标行与图上标记联动|明确缺的是连通、花窗还是特定位置|
|无候选修复|“暂无满足本题要求的建议”＋手动修改/回看入口|不装作算法万能|
|作品为空|简短空状态＋新建按钮|不添加无用筛选/搜索|
|保存失败|“尚未保存到浏览器”＋导出项目按钮|用户仍可继续，但明确备份状态|
|切课|先保存，成功后切换；保存失败保留原页面|复用现有保护逻辑|

错误反馈与成功吐司可以并存，但错误在解决或主动关闭前不要只靠自动消失吐司。禁止把“复制一段技术异常栈”作为用户提示。

## 6. 动效与可选介绍片（P2-01）

P1只需要蒙层显隐、卡片切换和现有分步展开的轻量反馈：显隐约160–220ms，步骤过渡180–280ms，避免所有组件使用弹簧。页面离开或隐藏时停止装饰动画；减少动态效果时直接切状态。

可选15–20秒点播短片分镜：

|时间|画面|字幕|真实性要求|
|---|---|---|---|
|0–3s|一张红纸与镂空花叶，标题进入|“一张纸，先想，再剪。”|可使用原创装饰SVG或AI封面；不冒充软件输出|
|3–6s|真实界面的折叠纸与预测入口|“先猜一猜，展开会怎样？”|不展示正式迁移题答案|
|6–10s|从边缘剪入，逐层展开|“一处剪口，映出对称。”|使用内核同一图形的阶段结果|
|10–14s|展示分离、回看与修正对照|“留住连接，读懂这一刀。”|展示合法候选，标明需要新纸制作|
|14–18s|真实打印模板、100mm标尺|“把屏幕上的发现，带到手心。”|未实剪时只展示数字模板|
|18–20s|开始按钮与工作台|“开始我的第一剪”|可立即进入，不自动循环|

控制：播放/暂停、跳过、重播；字幕与文字摘要齐全；默认无声；加载失败直接显示静态说明。不要强制先看完短片，也不要漫游完又强弹短片。

可交给图像生成工具的**装饰素材提示词草案**（开发阶段需要时使用，本轮未生成）：

> 为中文剪纸几何学习网站创作一幅原创横向纸艺插画。暖米色纤维纸底，朱砂红的团花、连续花叶和少量窗格影，红纸有真实的镂空负形、平整切边和很轻的层叠阴影。画面右侧聚集纹样，左侧留约一半干净空间供网页放标题。气质热烈而克制、朴素而精巧，像一间安静的中国民间纸艺工坊。不要文字、水印、人物、商标、金属金色、霓虹、玻璃、3D玩具质感或满屏节庆符号。此图仅为原创装饰示意，不仿制任何具体馆藏、非遗传承人的作品，不表现成已经完成的实剪实验照片。

生成后人工/开发者检查轮廓、意外字符、装饰与真实模板的区别；记录工具、日期、提示词、是否修改和采用理由。不要为塞满页面而批量生成图片。

## 7. 最小记录补齐与兼容（P1-06）

本轮不建设后台分析。优先服务已计划的8–12人观察，让导出的本机记录可区分任务和辅助。

### 7.1 必要数据

|事件|最少信息|
|---|---|
|attempt_start|attemptId、lessonId、condition/feedbackMode、origin（practice/onboarding/study）、起始时间|
|prediction_submitted|原始选项、是否已经看过结果、题目版本|
|cut_rejected|错误码、操作类别、新增/修改、关联刀号；不保存敏感输入|
|cut_applied|新增/修改/修复、关联刀号、结构片数/孔数|
|hint_opened|提示或候选类型、首次使用时间|
|attempt_end|完成/中止/离开、目标通过、辅助状态、总经过时间|

所有新事件有唯一eventId，尝试有唯一attemptId；重复导出按eventId去重。教程不是正式试用，origin必须区分。导出只从本机下载，不自动发送服务器。解释是否真的被理解仍用主持人原话记录，不让模型打分替代。

### 7.2 最小兼容实现建议

当前项目JSON是schemaVersion=1，`parseProject`严格拒绝未知字段；**不能直接往事件对象随意加字段而忘改解析与回归**。

在小范围实施中可保持现有事件外层 `{at,type,lessonId,value}`，用有类型的编码函数把新元数据存进 `value` 的JSON字符串（包括 `eventVersion:2`、eventId、attemptId等），继续遵守4096字符限制。新记录导出器输出明确的 `recordSchemaVersion:2` 并将它规范化成可读字段；旧纯文本事件标记 `legacy=true`，不猜补不存在的开始时间或拒绝次数。项目文件仍可按v1往返，旧工具最多不理解新事件语义，但不能损坏几何。

这是一条控制改动量的建议。如果开发者选择正式升级项目schema，则必须同时实现v1迁移、保存/载入/导出/错误提示与往返测试，不能只改类型文件。不要为这次小样本观察顺带重建全套存储层。

事件追加继续遵守现有revision一致性检查；不为新日志额外再发一次几何计算。若后续要分离几何revision与文档revision，需要单独证明打印和过期结果保护仍然成立，不能在本轮顺手“优化”出旧结果被当新结果的问题。

时间默认称 `elapsedMs`，表示总经过时间；未实现可见性/活动计时时不要标成“有效学习时间”。累积超过记录上限时显式说明截断，不静默宣称完整行为日志。
