**当前版本：第四版 0.4.0。** 本机体验：[打开第四版](http://127.0.0.1:5192)，或双击 `启动第四版.cmd`。五套主题、清晰可调的本地音乐、紧凑布局、正确导航、五类离线教学片段、学习进度与分享卡已接入。最终验收见[第四版交付记录](docs/v4-implementation/README.md)，素材出处见[来源登记](docs/content-sources.md)。

**本轮新增：工坊介绍短片与工坊指南。** 约 98 秒真实页面影片，带中文讲解、字幕和筝类拨弦配乐。首访可以看短片或进入六步引导，短片平滑收进侧栏；「工坊指南」整合网站介绍、原操作手册和五人职责。成片、口播、分镜、来源及本轮验收见 [短片交付记录](docs/v5-video/README.md)。

第四版使用独立 `dist-v4`，旧第三版5190仍读取 `dist`；5187/5189/5190既有服务未停止。不同端口存档不共享，可从旧版导出项目JSON再导入本版。

一间连接屏幕与纸张的剪纸结构与几何交互实验工坊。用于成年初学者、通识课程及手工社团。先预测，再折剪、观察结构变化、修改设计，最后打印与实剪对照。

## 本机启动

已核验环境：Windows、Node.js 24.15.0、npm 11.12.1。所有命令只在本目录执行。

开发：`npm ci` 按锁定版本安装依赖后执行 `npm run dev`。

第四版交付：执行 `npm run build`，再双击 **启动第四版.cmd**，在浏览器打开 **http://127.0.0.1:5192**。已有构建只需 Node；四首音乐与五类教学片段包含在本地目录，核心工坊无需外网。结束服务使用终端 Ctrl+C。本项目不自动结束占用端口的进程。

第四版生产／开发默认5192；E2E专用dev服务默认5194，避免platform测试误用生产包。服务仅绑定本机，不读取相邻项目。不要直接双击 dist-v4/index.html：浏览器模块及计算 Worker 需要通过本地 HTTP 服务加载。

历史0.1.0运行包与源码快照仍保留在 `artifacts/`；`artifacts/video/软件实际操作演示.webm` 也是旧版录屏，不代表第三版界面。第三版新截图、测试记录见 `docs/v3-implementation/evidence/`，当前打印文件位于 `artifacts/print-samples`。

## 使用顺序

1. 首次可选「先看短片」或「跟着做一遍」，也可直接进入；「纸上第一课」七任务保留。已有作品直接恢复，侧栏短片与顶栏「工坊指南」随时可用。
2. 按任务作出预测；在折叠画布上绘制矩形、三角形或简单多边形剪口。
3. 查看展开结果、保留区域数量、孔洞和首次新增分离的步骤。
4. 使用历史回放和前后对照；修改设计后重新制作，不能把已剪掉的纸补回。
5. 保存项目JSON作为独立备份；浏览器本地存储可能被清理，不能代替文件备份。
6. 导出SVG或打印模板。打印选择A4、100%/实际大小，关闭页眉页脚，先测量100mm标尺。

## 本版边界

2/4/8层固定折法，首刀之后更换折法须新建。纸张边长80–180mm，默认160mm；最多100刀，每刀最多64个顶点。几何坐标以纸心为原点，单位mm，0.01mm计算网格。仅支持当前折叠纸边界可进入的剪口，全部叠层同时裁切。内部洞可通过折线切口展开产生。

结构判断解释的是几何及本题目标，不预测材料韧性、剪刀可达角度、纸层错位或真实撕裂。仅点接触、退化等情况保守提示。自由创作中的多片图案不是艺术错误。

## 验证与参赛材料

- `npm test`：几何、文件校验、课程与输出测试。
- `npm run typecheck`、`npm run build`：类型检查与构建（含205项对比度护栏）。
- `npm run check:contrast`、`npm run check:layout`：主题对比度与七档尺寸布局检查。
- `npm run test:e2e`：本机Chrome和Edge端到端测试。
- `npm run samples`：生成并检查17组当前打印样例（HTML/SVG/JSON）；PDF生成入口为 `npm run samples:pdf`，历史PDF不混当第三版成果。
- `npm start` 后在另一终端运行 `npm run verify:production`：阻断外网请求验证打包版本。
- `npm run package:local`：整理包含构建、启动入口、文档和打印样例的运行包。
- `docs/v4-implementation/README.md`：第四版134单测、106双浏览器E2E、生产零错误、截图与待验证事项。
- `docs/v3-implementation/README.md`：第三版实际执行结果；`docs/test-report.md` 保留初版历史。
- `docs/manual-validation.md`：实剪与用户试用流程和空白记录。
- `docs/prior-art.md`：先例及技术选型。
- `docs/ai-use-log.md`、`docs/human-decisions.md`：如实记录AI参与与人工决策。

实剪照片、打印测量、访谈与真人试用需由实际参与者提供。空白记录和自动化测试不是用户效果证据。公开部署、作品报名与正式提交需另行安排。
